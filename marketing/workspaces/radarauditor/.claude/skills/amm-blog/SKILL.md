# Blog article

## Before writing

1. Run `/prime` if it has not run in this session.
2. Read `kanaele/blog.md`. If an article already covers the subject, report that with the
   date and the file, and propose angles that are not covered. Do not write the second
   article.
3. Read the curated analyses the subject touches.

## The draft

- The title states the finding, not the topic. "Why X" beats "About X".
- Lead with the thing that is true and uncomfortable, then explain it. An article that
  warms up for four paragraphs is read by nobody.
- Every figure carries its source inline. Link the primary source, not a blog that quotes
  it.
- Sections exist because the argument turns, not because the piece needs breaking up.
- Where the honest answer is "it depends", say what it depends on. That is usually the
  most useful paragraph in the piece.

## After writing

Write the draft to `inbox/` and add an entry to `kanaele/blog.md` with status `draft`, the
date and the path. Do not publish.
